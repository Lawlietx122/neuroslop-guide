/01quick_start

Три шага на запуск.

Импортируй пресет

В SillyTavern: API → Импорт пресета → neuroslop_v3.json. Применить к чату.

Включи нужные игры

По дефолту базовые блоки включены, игры — выключены. Открой боковую панель, поставь галочки на тех играх, в которые хочешь играть.

Напиши в чат

Пиши /game_mode — чар откроет меню. Дальше /play [номер]. Всё.

Чем больше игр включено — тем больше токенов жрёт пресет, даже когда ты в них не играешь. Включай только то, что реально нужно сегодня.

/03fair_vs_trickster

Это про честность чара. Включи один из двух.

🎯Fair Playчар играет честно. Подсказки правдивые, секрет не меняется.DEFAULT
🃏Tricksterчар может мухлевать — врать в подсказках, менять секрет.OFF

Когда какой

Fair — когда хочешь нормально поиграть. Виселица, Контакт, 20 вопросов — всё по правилам. Чар сохраняет характер в комментариях, но не жульничает.

Trickster — когда хочется драмы. Чар может тебе соврать. Ловишь командой /проверка — если мухлевал, признается. Если нет — отболтается, и раунд за ним.

Мухлёж работает только там, где есть что скрывать — Виселица, 20 вопросов, Допрос, Чёрный ящик. В Импров-театре, Дилеммах, Письме без адресата — мухлевать нечем.

/04replace_vs_overlay

Это про то, как игра живёт внутри сюжета.

🎬Replaceигра ставит РП на паузу. Чисто игровой режим.DEFAULT
🎭Overlayигра внутри сюжета. Сели у костра — играем в Виселицу. В роли.OFF

Когда какой

Replace — когда чисто поиграть. Сюжет не мешается, чар становится «ведущим», но в своём голосе. Удобно для длинных игр (Квест, Апокалипсис).

Overlay — топ для атмосферы. Игра вплетается в сцену: «*чар чертит палкой на песке* — шесть букв, подсказка — предмет». Проигрыш можно сделать частью сюжета («проиграешь — расскажешь секрет»).

Для коротких словесных игр — бери Overlay. Для длинных и механичных — Replace, иначе чар запутается между ролями.
